# 🚀 Mars Kolonisi Projesi

## 📌 Proje Hakkında
Mars Kolonisi, gelecekte Mars gezegeninde insan yaşamının nasıl mümkün olabileceğini ele alan bir projedir. Proje kapsamında Mars'ta yaşam, koloni kurulumu ve uzay teknolojileri görsel olarak tanıtılmaktadır.

## 🎯 Projenin Amacı
- Mars'ta insan yaşamını tanıtmak.
- Geleceğin uzay kolonilerini görselleştirmek.
- Mars'ta sürdürülebilir yaşam fikrini incelemek.
- Uzay araştırmalarına yönelik farkındalık oluşturmak.
